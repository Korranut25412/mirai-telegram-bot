# มิไร (Mirai Kuriyama) — บอท Telegram คุยกับ Claude

คุยกับ Claude (ในบทมิไร) จากมือถือผ่าน Telegram ใช้แพ็กเกจ Claude เดิม (บอทเรียก `claude -p` บนคอมนี้ ไม่ใช้ API key)
ค้นเว็บได้ ตอบไทยแทรกศัพท์อังกฤษแบบ **word** (แปล) ตามกติกาใน CLAUDE.md กลาง (บอทเก็บศัพท์ลง workspace/vocab.md อัตโนมัติ) และข่าวเช้า 07:00 แบบหัวข่าวอังกฤษ + เนื้อไทยแทรกศัพท์ + ศัพท์ 5 คำ + แกรมม่า 1 จุด

> คอมต้องเปิดอยู่และไม่ sleep บอทถึงจะตอบได้

## ติดตั้งครั้งแรก (ทำเอง ~5 นาที)

1. **ล็อกอิน Claude CLI**: เปิด PowerShell แล้วรัน `claude auth login` แล้วล็อกอินในเบราว์เซอร์ด้วยบัญชีที่มีแพ็กเกจ
   เช็กด้วย `claude auth status` ต้องขึ้น `"loggedIn": true`
2. **สร้างบอท**: ใน Telegram ทัก **@BotFather** → `/newbot` → ชื่อ `Mirai Kuriyama` → username `korranut_edit_bot` → ได้ token มา
   ต้องเป็นบอทใหม่ ห้ามใช้ token ของบอทจดขาย @korranut_ledger_bot (ใช้ร่วมกันไม่ได้ จะชนกัน)
   ไม่บังคับ: `/setuserpic` ใส่รูปโปรไฟล์ · `/setdescription` ใส่คำอธิบาย
3. **ใส่ token**: คัดลอก `.env.example` เป็น `.env` แล้วใส่ `TELEGRAM_BOT_TOKEN=...`
4. **หา chat id**: ดับเบิลคลิก `start_bot.bat` → ทักบอทใน Telegram (ส่งอะไรก็ได้) → บอทจะตอบเลข chat id
5. ใส่เลขนั้นใน `.env` เป็น `ALLOWED_CHAT_IDS=เลข` → ปิดหน้าต่างบอทแล้วเปิด `start_bot.bat` ใหม่
   ตั้งแล้วบอทจะตอบเฉพาะเรา คนอื่นทักมาจะถูกเมิน

## ใช้งาน

| พิมพ์ | ได้อะไร |
|---|---|
| ข้อความอะไรก็ได้ | คุยกับมิไร (จำบทสนทนาต่อเนื่อง) |
| `ข่าว NVDA` | สรุปข่าวล่าสุดของเรื่องนั้น |
| `แปล ...` | แปล + ศัพท์จากประโยค |
| `อังกฤษล้วน` / `กลับไทย` | สลับให้ตอบอังกฤษทั้งข้อความ / กลับมาไทย |
| `ทวนอังกฤษ` | ถามทวนศัพท์/แกรมม่าที่เคยได้ |
| `/vocab` | ศัพท์ 15 คำล่าสุด (เก็บอัตโนมัติใน `workspace\vocab.md`) |
| `/new` | เริ่มบทสนทนาใหม่ |
| `/daily` | สรุปข่าวเช้าเดี๋ยวนี้ |
| `/files` · `/get ชื่อไฟล์` | ดูรายงานที่เก็บไว้ / ขอเป็นไฟล์ |
| `/status` · `/id` | สถานะบอท / chat id |
| ส่งไฟล์หรือรูป | ให้ Claude อ่าน (ใส่คำสั่งใน caption ได้) |

- คำตอบยาวเกิน 4,096 ตัวอักษรจะแบ่งเป็นหลายข้อความ ถ้าเกิน 6 ข้อความจะส่งส่วนแรก + ไฟล์ `.md` ฉบับเต็ม
- สรุปข่าวเช้าเก็บไว้ใน `reports\` ด้วย

## ส่งรายงานจากคอมเข้ามือถือ

```
python notify.py "C:\path\รายงาน Nvidia.md"
python notify.py "C:\path\รายงาน.pdf"
python notify.py -m "ข้อความสั้น"
```
ไฟล์ `.md`/`.txt` ส่งเป็นข้อความ (ใส่ `--file` ถ้าอยากได้เป็นไฟล์แนบ) ไฟล์อื่นส่งเป็นไฟล์แนบ

## ปรับแต่ง

- `system_prompt.md` — โหมดมือถือของมิไร ข้อมูลผู้ใช้ ข้อจำกัดบนมือถือ คำสั้นที่ใช้สั่ง (ไม่ขึ้น git — คัดลอกจาก `system_prompt.example.md`)
- กติกาฝึกอังกฤษและกติกาอื่นมาจาก `~/.claude/CLAUDE.md` (ใช้ร่วมกับทุกแชท)
- `daily_prompt.md` — หัวข้อสรุปข่าวเช้า หุ้นที่ติดตาม
- `.env` — เวลาส่งข่าว (`DAILY_TIME`), เครื่องมือที่อนุญาต, โฟลเดอร์ที่ให้อ่านได้ (`EXTRA_READ_DIRS`)
  ค่าเริ่มต้นให้ Claude **ค้นเว็บและอ่านไฟล์ได้อย่างเดียว** แก้/ลบไฟล์หรือรันคำสั่งไม่ได้

## เปิดบอทอัตโนมัติตอนเปิดเครื่อง

กด `Win + R` → พิมพ์ `shell:startup` → คลิกขวาลาก `start_bot.bat` ไปวาง เลือก **Create shortcut here**

## แก้ปัญหา

- ดู log ใน `bot.log`
- บอทตอบว่า Claude ไม่ได้ล็อกอิน → รัน `claude auth login` ใหม่
- ขึ้น 409 → มีบอทอีกหน้าต่างรันอยู่ ปิดให้เหลือหน้าต่างเดียว
- ทดสอบ Claude โดยไม่ผ่าน Telegram: `python bot.py --selftest "คำถาม"`
- `.env` อยู่ใน OneDrive จะซิงก์ขึ้นคลาวด์ด้วย ถ้า token หลุดให้ไป @BotFather → `/revoke`
